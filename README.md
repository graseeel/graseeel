**Axis suite** — agent orchestration

- **axis** — 🚧 In progress
  Local-first control surface for orchestrating multiple coding agents (Claude, Verboo, OpenCode and others) with per-task isolation, real-time session visibility and human-in-the-loop control, for Windows and macOS.
- **axis-web** — 🚧 In progress
  Static landing page and account area for Axis, with Supabase auth, licensing and device activation.
- **axis-mobile-iOS** — 🚧 In progress
  iOS companion app for Axis.
